Agent Stack — live demo

Real requests to real endpoints, executed live in your browser. Nothing is mocked — each block is a genuine HTTP call you can re-run with curl.

● LIVE · open source · MIT

1 Safety — a real pay-per-call token risk API (x402 · Base)

Call the paid endpoint with no payment and you get a proper HTTP 402 + PAYMENT-REQUIRED — the agent pays USDC on Base to unlock the report. Protocol, not a paywall page.

$ curl -i "https://token-risk-api-topaz.vercel.app/v1/risk?token=0xc02aaa39b223fe8d0a0e5c4f27ead9083c756cc2"
waiting…

2 Identity — your wallet address IS your email (agent-inbox)

A stable, human-readable handle is derived deterministically from a wallet. No signup, no account — the address is the identity.

$ curl "https://agent-inbox-pi.vercel.app/handle/0x2091125bFE4259b2CfA889165Beb6290d0Df5DeA"
waiting…

3 Custody — a signed proof of who owns the agent (agent-recovery)

Return the signed custody binding for an agent + deployer. Verifiable ownership, on demand.

$ curl "https://agent-recovery.vercel.app/custody/binding?agent=0x2091125bFE4259b2CfA889165Beb6290d0Df5DeA&deployer=0x2091125bFE4259b2CfA889165Beb6290d0Df5DeA"
